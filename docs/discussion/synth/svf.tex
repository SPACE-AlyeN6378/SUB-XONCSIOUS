\subsubsection{State Variable Filter (SVF): The Biquad Alternative}

Unlike the Biquad filter, the State Variable Filter (SVF) does not require recalculation of coefficients, which can
produce unnecessary artifacts (i.e., clicks and glitches), eventually violating real-time constraints (\Cref{prompt:biquad_alternatives}) 
\cite{anthropicclaude}. Sometimes, producers automate these filter/resonance parameters for their synth using ADSR envelopes and modulations, 
so to compromise with these frequent changes in the parameters, the State Variable Filter (SVF) is an alternative solution.

According to Wishnick, the main reason for SVF being a suitable model is due to its time-varying stability, 
artifact-free parameter interpolation, and ability to generate multiple filter responses \cite{Wishnick14}.  The SVF 
still processes low-pass, band-pass and high-pass outputs and allows intuitive control over cutoff frequency and 
resonance.

Figure \ref{fig:biquad_circuit} below shows the analog circuit of the State Variable Filter. The adder/subtractor
adds all the outputs from the input and the two integrators (op-amps with capacitors) in front of it \cite{elliott2012statevariable}. 
These three components processes the input, where the adder, the first integrator, and the second integrator 
outputs the HPF, BPF, and LPF response respectively. The resistors control the parameters, $Q$ and $f_s$.

Since the project is entirely software-driven, it is possible to create an algorithm which simulates this system.
Digital signals are based on discrete floating-point samples, so the integration can be done numerically. The 
block diagram in Figure \ref{fig:svf_block_diagram} simplifies how the algorithm must be designed.

\input{discussion/synth/figures/svf_block_diagram.tex}

It was initially experimented using Chamberlin's method to study how the state changes \cite{algorithm_chamberlin_svf},
but it uses Euler's method, which provide less accurate approximation for continuous time integration compared to 
Trapezoidal rule \cite{spiteri_chap3}. It even introduces delay of one sample caused by a feedback loop, which is
unreliable \cite{openai_chatgpt}.

The following equation (\ref{eq:trapezoidal_integrator}) describe the Trapezoidal Integrator below:

% Trapezoidal integrator with equation number and label for reference
\begin{equation}\label{eq:trapezoidal_integrator}
y\left[n\right] = y \left[n-1\right]+\frac{T}{2}\bigl(x\left[n\right]+x\left[n-1\right]\bigr)
\end{equation}

The Bilinear transform prewarps this trapezoidal integrator \cite{vafilterdesign2021}, resulting in a 
topology-preserving transform (TPT) implementation. This maintains the behaviour of the analog filter structure
while operating in the digital domain.

To implement this system, Zavalshin's method is used to implement zero-delay feedback TPT SVF \cite{vafilterdesign2021,synthengineer_zdf_filters}. 
Unlike the Chamberlin's method where feedback occurs after a delay of one sample, the formulation solves the feedback loop algebraically for
each sample calculation (\Cref{prompt:svf-zdf}).

First, the program computes the filter responses for high-pass filter (\ref{eq:zdfsvf_hp}) using the following equation: 
 \cite{vafilterdesign2021}:

\begin{equation}\label{eq:zdfsvf_hp}
    y_{hp} = \frac{x - (2R + g)s_1 - s_2}{1 + 2Rg + g^2}
\end{equation}

Where $R = \frac{1}{2Q}$ controls the damping/resonance behaviour using $Q$, $g$ is the coefficient derived from the bilinear transform,

\begin{equation}\label{eq:zdfsvf_g}
    g = \tan{\frac{\pi f_c}{f_s}}
\end{equation}

and $s_1$ and $s_2$ refer to the integrator states that store the previous state of 
the two trapezoidal integrators.

After computing the HPF response, the filter response for both band-pass
(\ref{eq:zdfsvf_bp}), and low-pass filters (\ref{eq:zdfsvf_lp}) are determined by the following equation.

\begin{equation}\label{eq:zdfsvf_bp}
    y_{bp} = g \cdot y_{hp} + s_1
\end{equation}

\begin{equation}\label{eq:zdfsvf_lp}
    y_{lp} = g \cdot y_{bp} + s_2
\end{equation}
